## Installation Needed Before Use

- npm (if not already on computer)
- node (if not already on computer)

#### Dependencies Installation

- npm install express multer axios

### Start server (port 8000 by default)

node src/backend/b/server.js

### Or with custom FaceFusion endpoint

FACEFUSION_ENDPOINT=http://localhost:5000 node src/backend/b/server.js
