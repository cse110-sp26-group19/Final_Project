# Tuesday 05/05 Meeting Notes

## Date

Tuesday, May 5, 2026

## Discussion Summary

The team discussed the overall high-level direction and architecture for the MemeBro website and agreed on several core design decisions for the MVP.

## Agreed Decisions

### Image Storage

* User-uploaded photos should not be permanently stored in a database.
* Images should instead be processed temporarily during generation and discarded afterward.

### Meme Generation Pipeline

* The primary generation pipeline will use an external AI image API.
* The team agreed the most effective approach is to heavily structure the generation process through prompting.
* The pipeline will combine:

  * a user-uploaded image
  * a stored meme template/image from the application database

### Meme Selection

* Users should have two generation options:

  * randomly select a meme template
  * manually choose a meme template

### Result Exporting

* Users must be able to either:

  * download the generated meme
  * share the generated meme through some export/share functionality

### Performance Considerations

* The team agreed the product should prioritize speed and responsiveness.
* Fast generation times are important to preserve the “quick meme creation” experience.

### AI Model Discussion

* The team discussed potential token/API costs associated with image generation.
* Different model providers and approaches were debated.
* Discussion focused on balancing:

  * operational cost
  * generation quality
  * response speed
  * consistency of image editing/compositing capabilities
* The team acknowledged that not all models handle image merging/editing tasks equally effectively.

## General Notes

* Initial focus will remain on validating the workflow and MVP architecture before adding more advanced features.
* Further technical experiments and API testing will likely be required before finalizing the generation pipeline.
