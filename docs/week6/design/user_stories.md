# User Stories

1. As a fast group chat user, I want to generate a meme in under a minute so that I can send it while the conversation is still relevant.

2. As a mobile user, I want the app to work well on my phone so that I can create memes quickly without needing a desktop.

3. As a user with no caption idea, I want AI-generated caption suggestions so that I can quickly choose or modify a caption.

4. As a custom meme creator, I want to edit text placement and formatting so that I can better personalize memes.

5. As a user uploading a friend’s image, I want to preview the generated meme before saving so that I can verify the final result.

6. As a user, I want to download or share memes quickly so that I can easily send them through messaging platforms.

7. As a user, I want access to meme templates so that I do not need to start from scratch every time.

8. As a user, I want generated content to remain PG-13 so that the platform stays appropriate for demonstrations and public sharing.

9. As a returning user, I want access to previously generated memes so that I can revisit or reuse them later.

10. As a first-time user, I want the interface to be simple and easy to understand so that I can create a meme without needing instructions.

11. As a frustrated user, I want visible loading and progress indicators so that I know the app is still working during AI generation.

12. As a user who makes mistakes while editing, I want undo and reset functionality so that I can quickly recover without restarting the entire meme.

13. As a user concerned about inappropriate content, I want generated memes to be filtered and moderated so that offensive or harmful content is reduced.

14. As a user, I want a way to contact support or report issues so that I can notify the team about bugs, inappropriate content, or broken features.

15. As a mobile user with slower internet, I want meme generation to remain responsive and optimized so that the app still feels fast and usable.
