# Personas

## Persona 1 — Fast GC user

### Name
Bobby

### Description
College student who always sends memes in group chats and social media conversations with friends

### Goals
- Create memes quickly
- Send memes before the joke gets forgotten
- Use a simple mobile friendly workflow

### Pain Points
- Meme creation apps are slow
- Too many editing steps
- Hard to make memes quickly on mobile
- By the time he finish making a meme on his own, the joke is over

### Needs
- Fast upload process
- AI-generated caption suggestions
- Quick sharing and download options

## Persona 2 — Custom Meme Creator

### Name
Gilbert

### Description
User who enjoys making personalized memes using his friends photos and custom captions

### Goals
- Customize meme appearance
- Edit text placement and formatting
- Generate unique memes

### Pain Points
- AI output may not match intended joke
- Editing tools can feel limiting
- Existing meme tools feel outdated

### Needs
- Manual editing controls
- Real time preview
- Template selection options

## Persona 3 — Casual Meme User

### Name
Alex

### Description
Occasional meme user who wants help generating funny content quickly

### Goals
- Quickly create memes with minimal effort
- Get AI help for captions and ideas

### Pain Points
- Does not know which templates to use
- Has difficulty thinking of captions
- Does not want a complicated editor

### Needs
- Suggested templates
- AI caption generation
- Simple and guided user flow

---

## Persona 4 — Frustrated First-Time User

### Name
Karen

### Description
User with very little experience using meme-generation tools who becomes frustrated quickly when features are confusing or slow

### Goals
- Understand how to use the app immediately
- Quickly generate a meme without needing tutorials
- Feel confident that actions worked correctly

### Pain Points
- Confusing UI layouts
- Too many editing options at once
- Long loading times or unclear generation states
- Difficulty recovering from mistakes

### Needs
- Clear and simple navigation
- Visible loading/progress indicators
- Easy undo/reset functionality
- Helpful onboarding or guidance
- Access to support/contact information for reporting issues

---

## Persona 5 — Concerned Safety and Moderation User

### Name
Jordan

### Description
User concerned about inappropriate, offensive, or harmful AI-generated content and wants clear moderation standards.

### Goals
- Ensure uploaded images are used appropriately
- Avoid generating offensive or harmful memes
- Report inappropriate content or generation issues

### Pain Points
- AI may generate insensitive captions
- Fear of misuse involving personal photos
- Unclear moderation or reporting systems

### Needs
- PG-13 content filtering
- Reporting/contact system for problematic content
- Clear moderation guidelines
- Confirmation and preview before saving or sharing generated memes
