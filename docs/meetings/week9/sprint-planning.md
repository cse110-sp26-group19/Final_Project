## Work Focus & Approach

Backend work is organized into three focus areas rather than rigid sub-teams:

| Focus Area     | Responsibility                                                                                                    |
| -------------- | ----------------------------------------------------------------------------------------------------------------- |
| Implementation | Integrate the selected backend into the website                                                                   |
| Testing        | Tests for both the backend and the meme database                                                                  |
| Documentation  | Write ADRs for what we chose and why; clean up the repo; move unused backend code into a deprecated/research area |

Rather than locking people into fixed sub-teams, we took a **looser approach**: everyone is encouraged to independently contribute across these areas. The goal is broader, across-the-board participation in the repo — several people hadn't had much chance to show their own contributions, so the emphasis is on stepping up independently rather than leaning on a sub-team's work.
